# 데이터

원본 데이터 `Car.csv`는 POSCO 청년 AI·Big Data 아카데미에서 교육용으로 제공받은 자료라 이 저장소에 포함하지 않았습니다.

- 규모: 7,253행 × 13열
- 목표 변수: `Price` (중고차 가격, 단위: 천 원). 1,053건 결측
- 변수: Name, Location, Year, Kilometers_Driven, Fuel_Type, Transmission, Owner_Type, Mileage(kmpl), Engine(CC), Power(bhp), Seats, New_Price

노트북의 실행 결과(표·그래프)는 그대로 남아 있어 데이터 없이도 분석 과정과 결과를 확인할 수 있습니다.
